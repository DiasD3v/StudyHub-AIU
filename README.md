## Каталог товаров — CRUD

Откройте public/index.html через Live Server и перейдите в «API · CRUD».
Для работы нужен интернет; API-ключ не требуется.

- Товары отображаются карточками с фото, ценой, категорией и рейтингом.
- Нажатие на карточку открывает описание, рейтинг, цену, категорию и теги поверх сайта.
- Кнопка «Добавить товар» открывает форму; карандаш позволяет изменить товар.
- Корзина открывает подтверждение. «Оставить» отменяет удаление.
- Результаты операций и ошибки показываются всплывающими уведомлениями.
- Окна закрываются крестиком, Escape или нажатием на затемнённый фон.

В public/crud/index.html находится разметка, в style.css — стили,
в script.js — fetch-запросы и работа с DOM.
В DevTools → Network можно увидеть GET /products?limit=12,
POST /products/add, PATCH /products/ID и DELETE /products/ID.

DummyJSON не сохраняет изменения в базе. Новые товары редактируются и удаляются
локально, а изменения исчезают при обновлении каталога или страницы.
Для новых товаров без рейтинга отображается «Нет оценок», без фото — заглушка.

## Задание 5 — Todos и Users

Откройте `public/index.html` через Live Server и выберите «Задачи · Todos».
Страница задания находится в `public/task5/indexx.html`.

- Задачи загружаются из `GET https://dummyjson.com/todos?limit=0`.
- Исполнители загружаются из `GET https://dummyjson.com/users?limit=0&select=id,firstName,lastName,username`.
- `todo.userId` связывает задачу с `user.id`. Текст и статус берутся из `todo` и `completed`.
- Поиск по тексту задачи, имени, фамилии и логину исполнителя работает без учёта
  регистра. Поиск, сортировка и фильтр применяются ко всему списку задач из API.
- Сортировать можно по тексту задачи или имени пользователя в обоих направлениях.
  При сортировке по пользователю его задачи упорядочиваются по тексту.
- Нажатие на имя загружает профиль через `GET /users/ID`. В профиле показаны
  все задачи этого пользователя и их счётчики, независимо от фильтра поиска.
- «Добавить задачу» открывает форму с текстом, исполнителем и статусом и отправляет
  `POST /todos/add`. Новая задача появляется в списке и профиле исполнителя.
  Если поиск или фильтр скрывают новую задачу, они сбрасываются; сортировка сохраняется.
- Редактирование исходных задач отправляет `PATCH /todos/ID`, удаление — `DELETE /todos/ID`.
  Интерфейс меняется только после успешного ответа. При ошибке можно повторить запрос.
- Новые задачи получают уникальные временные ID: DummyJSON может вернуть один ID
  для нескольких добавлений. Их редактирование и удаление выполняются в текущей вкладке,
  поскольку на сервере эти задачи не сохраняются.

Локальные учебные примеры больше не используются. DummyJSON имитирует изменения:
они видны в текущей вкладке, а после перезагрузки вновь загружаются исходные данные API.
Старые записи задания 5 из `localStorage` не подмешиваются к данным сервера.

Проверка загрузки, связи пользователей и обработки ошибок API: `node --test tests/task5-data.test.cjs`.
