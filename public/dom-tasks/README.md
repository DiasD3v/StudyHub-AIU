# Практическая работа: DOM и классы элементов

## Как запустить

Скачайте репозиторий и откройте `public/dom-tasks/index.html` в браузере.
Также можно открыть `public/index.html` и выбрать в меню «Задания».
Установка библиотек и запуск сервера не требуются.

## Файлы

- `index.html` — исходные элементы страницы и подключение CSS/JavaScript.
- `style.css` — оформление страницы и стили класса `active`.
- `script.js` — выполнение обоих заданий, с комментариями на русском.

## Задание 1

1. `document.getElementById('greeting')` находит элемент по уникальному ID.
   Присваивание `textContent` меняет его текст на «Сәлем, әлем!».
2. `document.createElement('div')` создаёт элемент в памяти.
   `classList.add('new-div')` добавляет класс, а `textContent` — текст
   «Мен жаңа элементпін». `document.body.appendChild(newDiv)` вставляет
   этот элемент в конец `body`.
3. `document.querySelector('.old-element')` находит старый элемент по классу.
   Точка в селекторе означает поиск по классу. `remove()` удаляет элемент
   из DOM. Проверка `if (oldElement)` предотвращает ошибку, если он не найден.
4. `document.createElement('p')` создаёт абзац с текстом
   «Бұл ауыспалы абзац», затем `appendChild` вставляет его в контейнер.
5. `addEventListener('click', changeParagraphStyle)` назначает обработчик
   нажатия. Обработчик меняет `style.color` на фиолетовый (`#7c3aed`)
   и `style.fontSize` с 16 на 24 пикселя. Абзац также поддерживает Enter и пробел.

## Задание 2

Формулировка понимается как переключение класса: если `active` отсутствует,
добавить его; если присутствует — удалить.

- `classList.toggle('active')` выполняет обе операции и возвращает `true`,
  если после переключения класс присутствует, или `false`, если отсутствует.
- В CSS класс `.active` задаёт зелёные фон, рамку и текст.
- `Array.from(classTarget.classList).join(', ')` собирает все классы
  выбранного элемента в строку: `demo-box, bordered` либо
  `demo-box, bordered, active`.
- `console.log` выводит список в консоль, а `textContent` — в отдельный
  соседний `<p id="class-list">`. Вывод обновляется при загрузке и каждом нажатии.

Скрипт подключён с `defer`, поэтому выполняется после разбора HTML,
когда исходные элементы уже доступны.

## Что показать преподавателю

1. Открыть страницу: показать «Сәлем, әлем!» и новый `div` внизу.
2. В DevTools → Elements показать, что `.old-element` отсутствует,
   а `.new-div` — последний дочерний элемент `body`.
3. Нажать на абзац: текст становится фиолетовым и увеличивается до 24 px.
4. Открыть DevTools → Console, дважды нажать кнопку переключения класса.
   Сначала `active` появляется, затем исчезает; остальные классы сохраняются.
   Показать совпадающие списки в консоли и рядом с элементом.
5. Обновить страницу, чтобы вернуть начальное состояние демонстрации.

## Короткое объяснение своими словами

«DOM — это представление HTML-страницы в виде дерева объектов.
С помощью JavaScript я нахожу элементы по ID и классу, меняю их текст,
создаю новые узлы и удаляю старые. Создание элемента и добавление на страницу —
разные действия: сначала используется createElement, потом appendChild.
Для реакции на нажатие я назначаю обработчик addEventListener.
Во втором задании classList.toggle переключает класс active, а CSS определяет
его внешний вид. После каждого переключения я вывожу все классы выбранного
элемента в консоль и в отдельный абзац рядом».
