# Практическая работа: DOM и классы элементов

## Как запустить

Откройте `public/dom-tasks/index.html` в браузере или выберите «Задания»
в меню `public/index.html`. Установка библиотек и сервер не требуются.

Главная и два задания находятся на отдельных HTML-страницах. Верхние вкладки
и карточки на главной оформлены по образцу `Resume/Team-Resume`.
Активная вкладка выделена и отмечена `aria-current="page"`.
При новом открытии страницы задания его примеры возвращаются в исходное состояние.

## Файлы

- `index.html` — главная с выбором задания.
- `task-one.html` — работа с текстом, создание и удаление элементов.
- `task-two.html` — переключение класса `active`.
- `style.css` — общее оформление, вкладки и адаптация для телефона.
- `script.js` — обработчики нажатий для обоих заданий, с комментариями на русском.

## Задание 1

Демонстрации не выполняются автоматически при загрузке.

1. Нажмите на «Бастапқы мәтін». Скрипт находит элемент через
   `document.getElementById('greeting')` и меняет `textContent` на «Сәлем, әлем!».
   Повторное нажатие возвращает исходный текст.
2. Нажмите «Жаңа элемент қосу». Через `document.createElement('div')`
   создаётся `div` с классом `new-div` и текстом «Мен жаңа элементпін».
   `document.body.appendChild(newDiv)` добавляет его последним элементом `body`.
   Фокус переходит к новому блоку внизу страницы. Кнопка отключается, чтобы не создавать копии.
3. Нажмите на «Бұл ескі элемент жойылады.». Скрипт находит элемент
   через `document.querySelector('.old-element')` и удаляет его методом `remove()`.
   Рядом появляется подтверждение удаления.
4. Нажмите «Абзац қосу». Скрипт создаёт `p` с текстом «Бұл ауыспалы абзац»
   и добавляет его в `#paragraph-container`. Кнопка отключается.
5. Нажмите на созданный абзац: его `style.fontSize` меняется с 16 на 24 px,
   а `style.color` — на светло-фиолетовый `#c4b5fd`, контрастный на тёмном фоне.
   Повторное нажатие возвращает исходные стили.

Только создание двух новых элементов выполняется отдельными кнопками.
Изменение текста, удаление и изменение стиля выполняются нажатием на сами элементы.

## Задание 2

Нажмите на «Класы өзгеретін элемент».

- `classList.toggle('active')` добавляет отсутствующий класс или удаляет существующий.
- CSS `.demo-box.active` делает фон, рамку и текст зелёными.
- `Array.from(classTarget.classList).join(', ')` собирает все классы элемента.
- После каждого нажатия список выводится в консоль и в `#class-list`.
- Повторное нажатие убирает `active`, сохраняя `demo-box` и `bordered`.

## Доступность и проверка

Кликабельные тексты имеют `role="button"` и `tabindex="0"`.
Выберите их клавишей Tab и нажмите Enter или пробел. Переключаемые элементы
сообщают состояние через `aria-pressed`, результаты — через `role="status"`.
Скрипт подключён с `defer` и проверяет наличие элементов своей страницы.

Для демонстрации преподавателю:

1. Откройте главную, перейдите в каждое задание карточкой и верхними вкладками.
2. На первой странице убедитесь, что текст ещё исходный, старый элемент виден,
   а новый блок и абзац отсутствуют до нажатия кнопок.
3. Выполните все действия первого задания. В DevTools → Elements проверьте,
   что `.old-element` удалён, а `.new-div` — последний дочерний элемент `body`.
4. Во втором задании дважды нажмите на элемент. Сравните список классов
   на странице с выводом в DevTools → Console.
5. Повторите действия клавиатурой. Обновите страницу для сброса демонстрации.
