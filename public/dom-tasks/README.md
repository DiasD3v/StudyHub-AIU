# DOM: практические задания

Откройте `public/dom-tasks/index.html` в браузере. Сервер и библиотеки не нужны.
В дневнике (`public/index.html`) есть ссылка «Задания».

## Файлы

- `index.html` — главная и четыре задания в отдельных разделах.
- `style.css` — светлая и тёмная темы, общие стили.
- `script.js` — обработчики нажатий.

Вкладки сверху и кнопки в списке переключают разделы внутри одной страницы.
Адрес `index.html` не меняется, перезагрузки нет. Результаты действий сохраняются
при переключении вкладок. Созданный div виден только в первом задании.
Для перехода между вкладками с клавиатуры используйте стрелки, Home и End.
При перезагрузке страницы примеры возвращаются в исходное состояние, а выбранная тема сохраняется.

## Первое задание

1. Нажмите «Бастапқы мәтін»: появится «Сәлем, әлем!». Повторное нажатие вернёт текст.
2. Кнопка «Элемент қосу» создаёт div «Мен жаңа элементпін» в конце body.
3. Нажатие на «Бұл ескі элемент жойылады.» удаляет этот элемент.
4. Кнопка «Абзац қосу» создаёт абзац «Бұл ауыспалы абзац».
   Нажмите на него: размер изменится с 16 на 24 px, цвет — на фиолетовый.
   Повторное нажатие вернёт исходный стиль.

Новые элементы добавляются через `createElement` и `appendChild`.
Для удаления используется `remove`, для замены текста — `textContent`.
Кнопки создания отключаются после нажатия, чтобы не добавлять копии.

## Второе задание

Нажмите на «Класы өзгеретін элемент». Метод `classList.toggle('active')`
добавляет или удаляет класс `active`. Элемент меняет цвет на зелёный.
Список классов обновляется под элементом и в консоли браузера.
Остальные классы (`demo-box`, `bordered`) сохраняются.

Все действия выполняются после нажатия. Кликабельные тексты также доступны
с клавиатуры: Tab для выбора, Enter или пробел для нажатия.

## Третье задание

1. Введите количество строк и столбцов (целые числа от 1 до 50) и нажмите «Кесте құру».
   Функция `createTable(rows, columns)` создаёт таблицу заданного размера.
   Ограничение размера не даёт случайно создать слишком большую таблицу.
   Ошибочный ввод не удаляет уже созданную таблицу.
2. Выберите цвет в «Бояу түсі» и нажмите на ячейку. Её фон изменится.
   Повторное нажатие тем же цветом снимает окраску; «Түссіз» работает как ластик.
3. Под выбором цвета сразу показаны общее число закрашенных ячеек и количество
   ячеек каждого цвета, включая неокрашенные. Функция `countCellsByColor(color)`
   считает ячейки по значению `data-color`, а `showColorCount()` выводит все результаты.
   Подсчёт обновляется автоматически после создания таблицы, окрашивания и стирания.
   Неокрашенные ячейки не входят в общее число закрашенных.

Цвета хранятся в `data-color` ячеек, поэтому подсчёт не зависит от темы сайта.
Повторное создание таблицы очищает окраску. При переключении вкладок таблица сохраняется.
Ячейки доступны с клавиатуры через встроенные кнопки.

## Четвёртое задание

Нажмите переключатель «Қараңғы тақырып» вверху сайта или в четвёртом задании.
Функция `applyTheme(isDark)` задаёт `data-theme` у `html` и синхронизирует оба
переключателя. CSS-переменные меняют цвета всех разделов, элементов формы и текста.
Повторное нажатие возвращает светлую тему.

По умолчанию используется светлая тема. Выбор сохраняется в `localStorage`
под ключом `studyhub-dom-theme`. Если хранилище недоступно, переключение продолжает
работать до перезагрузки страницы.
